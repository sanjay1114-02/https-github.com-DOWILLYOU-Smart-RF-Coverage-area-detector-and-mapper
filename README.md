# Smart-RF-Coverage-area-detector-and-mapper
Mobile users regularly face call drops, weak data speeds, and complete signal loss in rural areas, indoor basements, tunnels, and hilly terrain.so genuine dead zones stay hidden for this problem a  budget friendly IoT device is created and the source code for the device and a prototype level dashboard lies here.self-contained, budget-friendly hardware (IoT tracker) detector that samples live cellular signal strength (RSSI) across available network bands using a dedicated cellular modem paired with a GPS receiver for precise geographic tagging.
